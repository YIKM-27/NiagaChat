# NiagaChat - Platform Chatbot Business

NiagaChat adalah platform all-in-one untuk menjual dan menggunakan chatbot AI, dirancang khusus untuk membantu bisnis digital Indonesia. Platform ini menyediakan solusi lengkap dari pembuatan chatbot hingga monitoring performa.

## 🚀 Fitur Utama

- **Chatbot Builder** - Platform drag-and-drop untuk membuat chatbot tanpa coding
- **AI-Powered Responses** - Teknologi AI terbaru untuk respons yang natural
- **Analytics Dashboard** - Monitoring lengkap performa chatbot Anda
- **Multi-Channel Support** - Deploy di website, WhatsApp, Facebook, dan lebih banyak
- **Security Enterprise** - End-to-end encryption dan GDPR compliant
- **24/7 Support** - Tim support siap membantu kapan saja
